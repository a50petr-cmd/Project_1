# Бот вакансий операционного директора

Telegram-бот для Петра Алексеева. По рабочим дням в 10:00 по Москве он ищет новые вакансии по всей России и присылает сопроводительное письмо под каждую. Просмотренные вакансии, письма и привязка чата хранятся в Cloudflare KV, а не на компьютере.

Бот сам отклик не отправляет.

## Что ищет

Роли по всей России: операционный директор (COO), Head of Operations, операционный менеджер, руководитель операционных проектов, менеджер проектов, руководитель направления, франчайзинг и развитие сети, e-commerce / e-grocery / доставка, руководитель B2B. Фильтр по зарплате выключен (`MIN_SALARY = "0"`): приходят вакансии с любой зарплатой и без неё. Чтобы включить, задайте минимум «на руки» в рублях.

Площадки: hh.ru, Зарплата.ру, Работа России, Хабр Карьера, SuperJob (если задан ключ API).

## Как приходит вакансия

1. Карточка: роль, компания, зарплата, почему подходит, ссылка и кнопки «✅ Откликнулся», «❌ Не подходит», «✍️ Другое письмо».
2. Отдельным сообщением — только текст письма, чтобы скопировать и вставить в отклик на hh.

Письмо пишет Workers AI (`@cf/meta/llama-3.3-70b-instruct-fp8-fast`) по фактам из `src/profile.ts`. Первая фраза — результат с цифрой, ближайший к вакансии. Бот проверяет ответ ИИ: если в нём есть цифры не из резюме, контакты или шаблонное начало, отправляется письмо из шаблона.

## Учёт откликов

После «Откликнулся» под карточкой появляются «🎉 Пригласили» и «🚫 Отказ». В 18:00 по рабочим дням бот спрашивает об откликах, на которые 5 рабочих дней нет ответа. По пятницам — сводка: отклики, приглашения, отказы и какие роли отвечают лучше. Команда `/stats` показывает то же в любой момент.

## Выкладка

GitHub Actions (`.github/workflows/deploy.yml`) на каждый push в ветку запускает тесты и `wrangler deploy`. Нужны секреты репозитория `CLOUDFLARE_API_TOKEN` (шаблон «Edit Cloudflare Workers») и `KV_NAMESPACE_ID`; `CLOUDFLARE_ACCOUNT_ID` — если у токена несколько аккаунтов. После выкладки `https://alekseev-job-bot.a50petr.workers.dev/health` отвечает `ok jobs-6`.

## Команды

- `/start` — привязать чат. Первый чат становится владельцем, если не задан `OWNER_CHAT_ID`.
- `/search` — прислать подборку сразу.
- `/pause` и `/resume` — ежедневная рассылка.
- `/stats` — статистика откликов.
- `/status` — версия, пауза, порог зарплаты и последний запуск.
- `/help`

Расписание: понедельник–пятница, 10:00 мск — подборка; 18:00 мск — напоминания, по пятницам сводка. Под полем ввода в Telegram есть кнопки: «Найти вакансии», «Статистика», «Пауза», «Включить», «Статус», «Справка». Праздники 2026 и 2027 по производственному календарю пропускаются. В один день уходит не больше 5 новых вакансий.

## Запуск на Cloudflare

Подойдёт бесплатный тариф Workers. В `wrangler.toml` не задавайте `[limits]`: на бесплатном плане Cloudflare отклоняет публикацию с `cpu_ms`.

```bash
npm install
npx wrangler login
npm run kv
```

Команда `npm run kv` печатает `id` namespace. Вставьте его в `wrangler.toml` вместо `replace-with-kv-namespace-id`.

Секреты:

```bash
npx wrangler secret put TELEGRAM_BOT_TOKEN
npx wrangler secret put WEBHOOK_SECRET
```

Необязательно:

```bash
npx wrangler secret put OWNER_CHAT_ID
npx wrangler secret put SUPERJOB_API_KEY
```

`WEBHOOK_SECRET` — любая длинная случайная строка. `OWNER_CHAT_ID` можно взять из ответа на `/start`, если хотите зафиксировать чат.

Деплой и webhook:

```bash
npm run deploy
export TELEGRAM_BOT_TOKEN=...
export WEBHOOK_SECRET=...
export WORKER_URL=https://alekseev-job-bot.<account>.workers.dev
sh scripts/set-webhook.sh
```

В Telegram: `/start`, затем `/search`.

Токен бота создаётся в [@BotFather](https://t.me/BotFather). Ключ SuperJob — в кабинете разработчика SuperJob, заголовок `X-Api-App-Id`.

## Проверка локально

```bash
npm test
npm run typecheck
npm run search
```

`npm run search` ходит в живые площадки и печатает письма в терминал, в Telegram ничего не отправляет.
